# Password Strength Analyzer

## 📌 Description
This is a GUI-based Password Strength Analyzer built using Python. It evaluates password strength based on length, complexity, and uniqueness.

## 🚀 Features
- Real-time password strength checking
- Classifies passwords as Weak, Moderate, Strong
- Suggests strong passwords
- Prevents reuse of old passwords using hashing (SHA-256)

## 🛠️ Technologies Used
- Python
- Tkinter
- Regex
- Hashing (SHA-256)

## ▶️ How to Run
1. Install Python
2. Save the file as password_gui.py
3. Run the program:
   python password_gui.py
